## Project Description

CareerPath is my Web Programming project. It is an application for IT companies and employees to track career development, skills, goals, learning resources, and career progression.

## Technology Stack

For the frontend, I use HTML, CSS, Bootstrap, and vanilla JavaScript.
For the backend, I plan to use FlightPHP, MySQL, PDO, and REST APIs.

## Project Structure

- frontend/views/ — HTML pages

- frontend/assets/css/ — CSS files

- frontend/assets/js/ — JavaScript files

- backend/rest/routes/ — API routes

- backend/rest/services/ — business logic

- backend/rest/dao/ — database queries

- backend/middleware/ — middleware

- backend/config/ — configuration

- backend/logs/ — logs

- docs/ — ERD and documentation

## Architecture and Naming Rules

I want to keep the frontend and backend separate. HTML pages should stay in the views folder, JavaScript routing in router.js, and frontend functionality in app.js.

For naming, use camelCase for JavaScript variables and functions, PascalCase for PHP classes, snake_case for database tables and columns, and lowercase names for files.
